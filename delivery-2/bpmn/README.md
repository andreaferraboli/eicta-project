## Edit

Open the files in https://demo.bpmn.io/ (drag and drop), refine the layout, then *Download* (overwrites the .bpmn) and *Export as image* (SVG/PNG) into the report figures folder.

The first version was generated by `tools/build_bpmn.py`. After you edit a file in bpmn.io, do not regenerate it: the script skips existing files unless `--force` is given, which would discard your edits.

## Validate

```
cd delivery-2/bpmn/tools
npm install
npm run validate
```

`validate.mjs` parses the files with `bpmn-moddle` (the library used by bpmn.io) and checks: every element has a layout shape, every node is in a lane, no dangling sequence flows, labelled decision branches, event-based gateways followed by catch events, message flows only between different pools.
